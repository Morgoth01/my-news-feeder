# Library

The Library is the saved-article workspace of My News Feeder.

It helps you work with articles you want to keep, revisit later, or store outside the normal `My Feeds` list.

## Open the Library

You can open Library sections in these ways:

- Use the `Library` area in the main window
- Open `Pinned` with `Ctrl+Alt+P`
- Open `Read Later` with `Ctrl+Alt+L`
- Open `Archive` with `Ctrl+Alt+A`

Each Library section opens in its own dedicated window.

## Library menus and controls

Inside the Library window you can work with several controls:

### Mode buttons

- Switch between `Pinned`, `Read Later`, and `Archive`

### Search and filters

- Search by title, note, feed, or link
- Filter by category, feed, label, read state, and date

### Sort and grouping

- Group by feed, category, archive date, month, or no grouping
- Change sort field and direction

### Preview panel

- Shows the selected article summary
- Lets you open the article window, switch to `Show Content` or `Reader Mode`, open the link externally, or copy the link
- In `Show Content`, `Allow Media` relaxes media blocking for the current page only. This helps some custom site video players, while autoplay stays off.
- In `Show Content` and `Reader Mode`, you can press `F11` to enter fullscreen
- Use `Exit Fullscreen` or `Esc` to leave fullscreen again

### Context menu

- Right-click selected articles for actions such as pinning, moving to Read Later, archiving, unarchiving, labeling, opening links, and copying links

### Labels and notes

- Create and manage reusable labels with the label manager
- Store your own named colors and reuse them later
- Assign labels from the article context menu
- Sort and filter Library items by labels
- Add private notes to saved articles for later reference

## Pinned

Use `Pinned` for articles you want to keep close at hand.

Typical use cases:

- important articles you want to keep visible
- reference items you may return to often
- articles you do not want to lose in the normal refresh flow

In `Pinned` you can:

- review pinned items in one place
- select multiple articles with the left checkbox column
- open an article with double-click
- move an item to `Read Later`
- archive it when you are done with it
- remove the pin when it is no longer needed

## Read Later

Use `Read Later` for articles you want to read when you have more time.

Typical use cases:

- longer articles you want to postpone
- articles worth reading but not immediately
- items you want separated from the normal feed stream

In `Read Later` you can:

- keep a reading queue
- select multiple articles with the left checkbox column
- open articles with double-click
- pin especially useful entries
- archive articles after reading
- remove items from `Read Later` when finished

## Archive

Use `Archive` for long-term storage of articles you want to keep.

Typical use cases:

- keeping older articles for later reference
- storing articles with notes or labels
- keeping articles out of the normal working views without deleting them from your saved workspace

In `Archive` you can:

- browse archived items in a dedicated window
- select multiple articles with the left checkbox column
- use notes and labels
- save filter and sorting setups as saved views
- use the preview panel and double-click article window
- unarchive items if you want to move them back out of the archive

## Retention and cleanup

The `Archive` section includes retention controls on the left side.

- You can enable automatic archive cleanup
- You can choose a retention period such as `7`, `30`, `90`, `180`, or `365` days
- Older archived items are deleted from the Archive according to the selected retention period
- `Apply Cleanup Now` runs the cleanup immediately
- A confirmation dialog appears before manual cleanup deletes archived articles

## Tips

- Use `Pinned` for active references
- Use `Read Later` for your reading queue
- Use `Archive` for long-term storage
- If the window feels crowded, hide the preview or reduce the controls area on smaller screens
