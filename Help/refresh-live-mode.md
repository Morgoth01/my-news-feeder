# Refresh and Live Mode

Use **Refresh** for manual updates, or enable **Auto Refresh** for periodic updates.

## Live Refresh

Live mode checks feeds in shorter intervals (60s / 30s / 10s).

- 60s is recommended for most setups.
- 30s is more aggressive.
- 10s (**may increase load or trigger timeouts/rate limits.**)

## Background Behavior

When Live Refresh is enabled, updates run in the background with reduced UI disruption.
