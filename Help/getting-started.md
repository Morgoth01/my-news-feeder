# Getting Started

Use this quick setup flow to start in a few minutes.

## First setup

1. Open `Manage Feeds`.
2. Add RSS/Atom feed URLs.
3. Optionally create categories.
4. Mark selected feeds as `Important`.
5. Click `Refresh`.

## Recommended first settings

- Keep Live Refresh at `60s` first.
- Enable only the feeds you really need.
- Use keyword filtering only if your feed volume is high.
