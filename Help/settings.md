# Settings

The Settings window is split into topics on the left and options on the right.

## General

- Dark Mode
- Show Content Always-On

## Terminal (Preview)

- Open app in Terminal Mode by default
- Choose the default terminal theme
- Enable or disable the terminal boot animation

## Refresh

- Auto Refresh interval
- Live Refresh (60s / 30s / 10s)

## Feed Settings

- Max articles per feed

## Adblocker

- Enable/disable AdBlocker
- Open AdBlocker details and manual list update

## Filtering and Notifications

- Hide advertisement-like articles by keyword
- Configure important keywords
- Enable desktop notifications for important items

## Tools

- Clear browser cache
