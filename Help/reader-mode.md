# Reader Mode

Reader Mode tries to extract clean article text for better readability.

## How to use

- Select an article.
- Click **Reader Mode** (or use the shortcut).
- Click again to return to feed summary view.

## Notes

- Some sites with heavy cookie walls may provide limited extractable content.
- You can also open an article in a separate window and use Reader Mode there.
